🐂 شەڕی نیو لای · NIU LAI FIGHT

یارییەکی 3Dی شەڕی دوو کەسییە و سەرچاوەکراوەیە · ڕێزلێنان لە «The King of Fighters» و «Ultraman Fighting Evolution»، گونجاوکردنی جیهانی فیلمی ئەنیمەیشنی 2026 ـی «牛来»

A 3D two-player fighting game built with Three.js — local versus & LAN multiplayer, zero asset pipeline.

[License] · [Three.js] · [Players] · [Fighters] · [Build]

[وێنەی شەڕی نیو لای: لێدانی پێی بەهێز و فڕاندنی دوژمن، لە کاتی لێداندا شرارە دەباری]

نیو لای بە یەک لێدانی پێی بەهێز، «باۆ لاه» بەرەو ئاسمان فڕێدەدات — پەڕەی تەندروستی، وزە و نیشاندەری کۆمبۆ هەمووی ئامادەن.

✨ ئەمە چییە؟

یارییەکی 3Dی شەڕی تەواو لە ناو وێبگەڕە:

- پێویستی بە دامەزراندن نییە.
- پێویستی بە build نییە.
- هیچ فایلێکی وێنە، مۆدێل یان دەنگی دەرەکی نییە.
- هەموو کاراکتەرەکان، دیمەنەکان، ئیفێکتەکان و دەنگەکان بە شێوەی پڕۆگراماتی دروست دەکرێن.

ئەم پڕۆژەیە لە شێوازی دیزاینی یارییە کلاسیکییەکانی شەڕ، وەک «The King of Fighters»، «Street Fighter» و «Ultraman Fighting Evolution» سوود وەردەگرێت و سیستەمی تەواوی شەڕی مۆدێرن جێبەجێ دەکات:

- داتای فریم بۆ هەر هێرشێک
- کۆمبۆ و Cancel
- Hitstop
- هێرشی تایبەت و وزە
- سێ دەوری شەڕ، دوو بردنەوە بۆ بردن
- Slow Motion لە کاتی KO
- شەڕی دوو کەسی لەسەر هەمان کۆمپیوتەر
- شەڕی LAN

کاراکتەر و جیهانی یارییەکە لە فیلمی ئەنیمەیشنی 2026 ـی «牛来» وەرگیراوە؛ چیرۆکی گۆڕانی گایەکی بچووک و ترسنۆکە بۆ شەڕکەرێکی بوێر.

ئەم کارە پڕۆژەیەکی فەن‌میدیا و غیرتجارییە.

🚀 دەستپێکردنی خێرا

git clone https://github.com/liyupi/niulai-game.git
cd niulai-game
npm install
npm start

پاشان ئەمە بکەرەوە:

http://localhost:3000

و یاری بکە.

🌐 یاریی LAN

دوای دەستپێکردنی سێرڤەر، ناونیشانی LAN لە Console ـدا پیشان دەدرێت، بۆ نموونە:

http://192.168.x.x:3000

ئەم ناونیشانە بۆ هاوڕێکەت بنێرە کە لە هەمان Wi-Fi ـدایە.

هەردوو یاریزان دەچنە ناو LAN Multiplayer و بە شێوەی خۆکارانە پێکەوە دەبەسترێن.

یاریزانەکەی زووتر دەچێتە ژوورەوە دەبێتە P1 / Host.

🧠 سیستەمی شەڕ

سیستەمەکە لە میتۆدی Frame Data ـی یارییەکانی شەڕ وەک KOF و Street Fighter وەرگیراوە؛ تەنها سیستەمێکی سادەی «ئەگەر لێی دا، خوێنی کەم بکە» نییە.

⚔️ Frame Data

هەر هێرشێک سێ قۆناغی هەیە:

1. Startup — ماوەی دەستپێکردنی هێرش
2. Active — ماوەی کاریگەری Hitbox
3. Recovery — ماوەی گەڕانەوە دوای هێرش

مشتە سووکەکان دەتوانن بە شێوەی خۆکارانە بۆ کۆمبۆ بەکاربهێنرێن، بەڵام هێرشە قورسەکان زیانێکی زۆرتر دەدەن و کاتی Recovery ـیان زۆرترە.

🔗 Cancel

هێرشی ئاسایی دوای سەرکەوتنی Hit دەتوانێت بۆ هێرشێکی تر Cancel بکرێت.

نموونەی کۆمبۆ:

مشتێکی سووک
→ مشتێکی سووک
→ مشتێکی قورس
→ هێرشی تایبەت

💥 Hitstop

لە ساتی لێداندا یاری بۆ چەند Frame ـێک دەوەستێت، بۆ ئەوەی هێرشەکە قورس‌تر هەست پێبکرێت.

لەگەڵ ئەمەش:

- Screen Shake
- Zoom Impact
- Sound Effect

بەکاردێن.

🌀 KO

کاتێک یاریزانێک KO دەبێت:

- یاری Slow Motion دەبێت.
- کامێرا نزیک دەبێتەوە.
- پاشان نیشانی K.O. پیشان دەدرێت.
